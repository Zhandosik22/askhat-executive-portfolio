# Askhat Turgynbekuly — Executive Portfolio

Premium executive portfolio website for construction, operations and digital transformation leadership.

## Run locally

Use VS Code + Live Server, or:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Latest features

- Dark / Light theme toggle with saved preference
- Full-screen mobile navigation
- Responsive hero with architectural visual + 3D canvas
- Interactive career timeline and global map
- Project showcase
- Education cards that expand on hover / tap
- KZ / EN / RU language switching
- Responsive mobile/tablet layouts
- Local project assets and CV

## Education placeholders

The expanded Education descriptions are temporary placeholder copy and are intentionally easy to replace later in `index.html`.
